# FastPDF สำหรับ Windows

FastPDF เป็นเครื่องมือ PDF สำหรับ Windows จาก **OZ Lab** สำหรับเปิด อ่าน ค้นหา
นำเสนอ พิมพ์ และจับภาพ PDF และสำหรับแปลง PDF เป็น PNG และแปลงภาพเป็น PDF

[English](README.md)

> **การเตรียมการเปิดตัว — ยังไม่มีการเปิดตัวให้ดาวน์โหลดได้ในขณะนี้**
> repository สาธารณะนี้ยังไม่มีตัวติดตั้ง แพ็กเกจ หรือลิงก์ดาวน์โหลดในปัจจุบัน
> ดู[สถานะการติดตั้ง](docs/installation.md)

## FastPDF ทำอะไรได้บ้าง

FastPDF เป็นแอปพลิเคชัน Windows แบบเนทีฟ ความสามารถระดับสูงที่เตรียมไว้สำหรับ
การเปิดตัวสาธารณะครั้งแรก:

- **เปิดและดู** — เปิด PDF, ลากไฟล์เดียวมาวางบนหน้าต่าง, หรือส่งพาธของไฟล์ผ่าน
  command line
- **อ่านและนำทาง** — เลย์เอาต์หน้าต่อเนื่องพร้อมซูม พอดีความกว้าง พอดีหน้า
  กระโดดข้ามหน้า และโหมดนำเสนอแบบเต็มหน้าจอ
- **ค้นหา** — ค้นหาข้อความภายในเอกสาร
- **พิมพ์** — พิมพ์เอกสารปัจจุบัน
- **แปลง** — PDF เป็น PNG และภาพเป็น PDF
- **จับภาพหน้าจอ** — เลือกพื้นที่บนหน้าแล้วคัดลอกไปยังคลิปบอร์ด
- **หมุนหน้า** — หมุนหน้าปัจจุบันและบันทึกสำเนาที่หมุนแล้ว

รายการนี้อธิบายตัวแอปพลิเคชัน ไม่ใช่ไฟล์ดาวน์โหลด ยังไม่มีบิลด์ที่ดาวน์โหลดได้
ในขณะนี้

## สถานะการดาวน์โหลด

**ยังไม่มีการเปิดตัวให้ดาวน์โหลดได้ในขณะนี้** ไม่มีตัวติดตั้ง แพ็กเกจ ไฟล์บีบอัด
หรือไบนารีใด ๆ เผยแพร่ใน repository นี้ ไฟล์จากที่อื่นที่อ้างว่าเป็น FastPDF
ไม่ควรเชื่อถือ

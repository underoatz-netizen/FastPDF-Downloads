# Support

## Status

FastPDF 0.3.2 is published as a 64-bit Windows release. Support is provided on
a best-effort basis for questions, feedback, and issue reports about the
application and its documentation.

## Reporting a problem or requesting a feature

Use this repository's GitHub issue forms:

- [Report a bug or request a feature](https://github.com/underoatz-netizen/FastPDF-Downloads/issues/new/choose)

Please **do not** include documents, personal data, credentials, license keys
or other sensitive information in an issue.

## Donations and supporting OZ Lab

FastPDF is freeware provided at no cost, with all features fully available and no paid tiers, subscriptions, or donation nag screens.

If you wish to voluntarily support OZ Lab's ongoing development and hosting, you can contribute via:
- **International:** [OZ Lab on Ko-fi](https://ko-fi.com/ozlab)
- **Thailand (PromptPay):** Visit the [OZ Lab Support & Donations page](https://underoatz-netizen.github.io/support/#donations) for the official PromptPay QR code.

All donations are entirely voluntary. This repository does not directly process or collect any payment information.

## What this page is not

This page is not a commercial support contract and makes no promise of response
times, fixes, features or release dates.

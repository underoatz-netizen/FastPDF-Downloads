# Support

## Status

FastPDF is in release preparation. There is no downloadable release at this
time, so support is limited to questions and reports about the project and its
documentation.

## Reporting a problem or requesting a feature

Use this repository's GitHub issue forms:

- [Report a bug or request a feature](https://github.com/underoatz-netizen/FastPDF-Downloads/issues/new/choose)

Please **do not** include documents, personal data, credentials, license keys
or other sensitive information in an issue.

## Donations and payment

No donation links are configured for this project. This repository does not
request payment and does not collect payment information.

## What this page is not

This page is not a support contract and makes no promise of response times,
fixes, features or release dates.
